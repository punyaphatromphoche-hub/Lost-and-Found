# 🎒 BJS3 Lost & Found (ระบบแจ้งของหายและค้นหาของที่หาย โรงเรียนบรรหารแจ่มใสวิทยา 3)

ระบบเว็บแอปพลิเคชันสำหรับศูนย์กลางแจ้งของหายและส่งคืนของที่พบภายในโรงเรียนบรรหารแจ่มใสวิทยา 3 เพื่อช่วยเหลือนักเรียน ครูอาจารย์ และบุคลากรในการติดตามของหายได้อย่างรวดเร็ว มีประสิทธิภาพ และตรวจสอบได้

---

## ✨ คุณสมบัติเด่น (Features)

1. **หน้าแรก (Landing Page)**: สรุปภาพรวมสถิติสิ่งของที่หายและเก็บได้ พร้อมแสดงรายการสิ่งของที่อัปเดตล่าสุด
2. **ค้นหาและคัดกรอง (Search & Filter)**: สามารถค้นหาด้วยคำสำคัญ (Keyword) เช่น ชื่อสิ่งของ หรือสถานที่ และคัดกรองตามหมวดหมู่สิ่งของได้
3. **หน้ารวมของที่หาย (Lost Items)**: รวบรวมรายการสิ่งของที่กำลังตามหา พร้อมรายละเอียด วันที่ และสถานที่คาดว่าหาย
4. **หน้ารวมของที่เก็บได้ (Found Items)**: รวบรวมสิ่งของที่พบและรอส่งคืนเจ้าของ พร้อมจุดติดต่อรับของ
5. **แบบฟอร์มแจ้งของหาย / พบของ (Report Form)**: กรอกข้อมูลแจ้งของหายหรือพบของได้อย่างสะดวก พร้อมระบุรายละเอียด รูปภาพ และช่องทางติดต่อ
6. **ดีไซน์ทันสมัยและรองรับมือถือ (Responsive UI)**: ออกแบบด้วย Tailwind CSS รองรับการใช้งานทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน พร้อมธีมสีประจำโรงเรียน

## 🛠 เทคโนโลยีที่ใช้ (Tech Stack)

- **Framework**: [Next.js](https://nextjs.org/) (Pages Router)
- **Frontend Library**: [React 18](https://react.dev/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/)
- **Utilities**: PostCSS, Autoprefixer

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (Getting Started)

### ข้อกำหนดเบื้องต้น (Prerequisites)
- [Node.js](https://nodejs.org/) (เวอร์ชัน 18.x หรือสูงกว่า)
- npm (มาพร้อมกับ Node.js)

### 1. ติดตั้ง Dependencies
เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:
```bash
npm install
```

### 2. รันโปรเจกต์ในโหมด Development
```bash
npm run dev
```
เปิดเบราว์เซอร์แล้วเข้าไปที่: [http://localhost:3000](http://localhost:3000)

### 3. Build สำหรับนำขึ้น Production (Production Build)
```bash
npm run build
npm start
```
